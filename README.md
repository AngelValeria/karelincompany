# Агент остатков Ozon KARELIN

Работает бесплатно на GitHub (файл `.github/workflows/stock-agent.yml`): раз в ~10 минут забирает команды бота,
каждые 3 часа проверяет остатки на складах Ozon и пишет в Telegram, если товара осталось меньше чем на 5 дней.
Утром (9:00 МСК) присылает сводку. Команды: /check, /status, /help. Ответ на команду приходит в течение ~10 минут.

## Секреты репозитория (Settings → Secrets and variables → Actions → New repository secret)
- `OZON_CLIENT_ID`: Client ID из кабинета Ozon (Настройки → API-ключи → Seller API)
- `OZON_API_KEY`: ключ с ролью только для чтения (например, Admin read only)
- `STOCK_BOT_TOKEN`: токен отдельного бота от @BotFather
- `STOCK_CHAT_ID`: необязательно. Бот сам запомнит того, кто первым напишет ему /start, и пришлёт chat id

## Как считается
- продажи: заказы за 30 дней / 30 (аналитика Ozon; если она недоступна для ключа, по заказам FBO)
- дней до нуля = остаток / продажи в день; партия = продажи в день × 14
- куда везти: партия делится по складам пропорционально тому, сколько товара там уже лежит.
  Свободные места на складах Ozon через API не отдаёт, их нужно смотреть в кабинете.

## Проверка
Вкладка Actions → «Агент остатков Ozon» → Run workflow: прогоняет тесты и сразу проверяет остатки.
Локально: `pip install -r requirements.txt`, `cp .env.example .env`, заполнить, `python run_once.py`, тесты `pytest test_mock.py -v`.
В логах GitHub пишутся только количества, без названий и цифр по товарам: репозиторий публичный.
